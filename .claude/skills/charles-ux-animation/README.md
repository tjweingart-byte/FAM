# charles-ux-animation

The 20 principles of UX and animation from my reel, as a procedure your agent walks whenever it builds or reviews an
interaction: should it move, where does the eye go, how does it move, can people find, hit and choose it, and can they
finish. It also carries Emil Kowalski's animation rules, Interface Craft's motion techniques and 13 more laws of UX.

## Install

```bash
npx skills add LemonFace0309/charles-skills --skill charles-ux-animation
```

Add `-g` to install it for every project, or copy this folder into `~/.claude/skills/` (Claude Code) or
`~/.agents/skills/` (Codex).

## Use

```text
/charles-ux-animation the add-to-cart flow
/charles-ux-animation review the motion in the onboarding screens
```

## Credits

1–12 are Disney's principles of animation from *The Illusion of Life* by Frank Thomas and Ollie Johnston. Most of the list comes from Raphael Salaja's [userinterface.wiki](https://www.userinterface.wiki), and the laws go deeper on Jon Yablonski's [Laws of UX](https://lawsofux.com). #20 and the animation rules and recipes are Emil Kowalski's ([animations.dev](https://animations.dev)), and the motion techniques come from Josh Puckett's [Interface Craft](https://interfacecraft.dev).
